Netflix Data Analysis Dashboard 🎬📊
This project is a comprehensive Netflix Data Analysis Dashboard created using Power BI. The dashboard provides insights into Netflix content, user watch behavior, ratings, subscription types, genres, countries, and customer engagement patterns. The project helps in understanding viewing trends and content performance through interactive visualizations.

**Project Overview**
The dashboard analyzes Netflix-related data and transforms raw information into meaningful business insights. It includes multiple charts, KPIs, filters, and visual reports to study audience preferences, ratings, watch time, and subscription usage.

**Features**
Analysis of watch time based on age groups
Genre-wise and country-wise rating analysis
Subscription type comparison (Basic, Standard, Premium)
Monthly content distribution trends
Movie vs TV Show performance comparison
Rating category analysis (High Rated / Low Rated)
Country-wise content and customer analysis
Director and cast performance insights
Interactive slicers and filters for better exploration

**Tools & Technologies Used**
Power BI Desktop
Data Cleaning & Transformation
Data Visualization
DAX Functions
Interactive Dashboard Design

**Dashboard Insights**
Adults and young adults contribute the highest watch time.
Movies and TV Shows have nearly equal engagement levels.
Premium and Standard subscriptions show higher average watch time.
Ratings and content popularity vary across different countries and genres.
Monthly analysis helps identify content release and engagement trends.

**Key Visualizations**
Bar Charts
Pie Charts
KPI Cards
Line Charts
Country-wise Analysis
Genre-wise Comparison
Rating Distribution
Subscription Analysis
